暗夜牌局 · 办公室疑云(离线版)
================================

【怎么玩】
直接双击打开 darktable-offline.html,Chrome / Safari / Edge 任意浏览器都行,
不需要联网、不需要装任何东西、不需要登录。

【游戏简介】
9 人本格推理游戏,发生在一家互联网大厂的封闭排查周:
核心项目「麒麟」数据连续外泄,你被召进会议室,要从 9 个同事里揪出内鬼。

- 开局:先看「汤面」(明面线索),再看你的身份卡
- 游戏:白天晨会发言 + 投票,夜晚内鬼行动 / 眼线查人 / 底牌使用
- 结局:看「汤底」(故事真相) + 全员身份揭晓

【你的身份可能是】
- 内鬼(3 人):联手把数据发给竞对,目标是让好人出局
- 眼线(1 人):每晚能查一个人是好是坏
- 有底牌的人(1 人):手里捏着保人和实锤两张牌
- 有后手的人(1 人):被冤枉走的时候能带走一个人
- 普通员工(3 人):没特殊能力,靠推理投人

【想改话术?】
包里附带 dialogue-library.js,里面是 NPC 的发言库。
改完想让游戏用上,需要:
1. 把这个文件放回 offline/ 目录
2. 在项目根目录跑 `node offline/assemble.mjs`
3. 新生成的 darktable-offline.html 就是你的版本

如果只是想自己玩,这个文件可以删掉,不影响游戏。
